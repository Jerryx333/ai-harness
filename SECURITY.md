# 安全报告 / Security reporting

支持的版本是 `main`。 / The supported version is `main`.

安全问题请通过本仓库 GitHub **Security** 页的 **Report a vulnerability** 提交私密漏洞报告，不要开公开 issue。报告中提供复现步骤、受影响的代码位置和影响说明；不要附真实凭据或私人数据。

Report security issues through **Report a vulnerability** on this repository's GitHub **Security** page. Use a private vulnerability report, not a public issue. Include reproduction steps, affected code and impact; do not include real credentials or private data.
